# Portal Layanan Resmi Pemerintah Kabupaten Semarang

Portal direktori layanan terpadu — akses satu pintu layanan kependudukan, perizinan, keuangan, informasi publik & pengaduan.

## Instalasi

```bash
npm install
```

## Menjalankan Proyek

```bash
npm run dev      # development server (http://localhost:5173)
npm run build    # build produksi ke dist/
npm run preview  # pratinjau hasil build
npm run lint     # cek lint (oxlint)
```

## Teknologi

React 19 + Vite + Tailwind CSS 4 + lucide-react.
